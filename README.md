# Black Friday — Юлия Гросу

Публичная версия лендинга с видео, контактной формой и передоплатой $20 через Stripe.

Форма передаёт заявку в существующий платёжный обработчик Etsy через `etsy_pay_4` и открывает `paymentUrl` из его ответа.

Передоплата составляет $20 USD. Начальный этап CRM — `106874727`, тип лида — `Горячий`. После оплаты передаются этап `106875715`, тип `Автооплата` и отметка `Бронь`.

Название сделки — `Предоплата с сайта ЧП 20$`. Теги — `399$/599$/899$` и `blackfriday`. Данные конкретного тарифа не передаются.

Обработчик получает адрес возврата после оплаты `https://www.juliagrosuschool.us/thanks`, как в исходной форме. Подтверждение оплаты и обновление CRM выполняет существующая серверная интеграция.

Оптимизация: Full HD-видео H.264/AAC с faststart, загрузка только после Play, WebP-фото с мобильной версией, постер видео и локальные WOFF2-шрифты. Удалены стили старого апсейла. Пульсация кнопок — 1,6 секунды, с отключением при reduced motion и отправке формы.

Это статический сайт. Для обычного хостинга достаточно `index.html` и папок `css`, `js`, `images`, `fonts`, `licenses`, `video`. Node.js и установка пакетов не нужны. Лицензии шрифтов находятся в `licenses`.
