# Black Friday — Юлия Гросу

Публичная версия лендинга с видео, контактной формой и передоплатой $20 через Stripe.

Форма передаёт заявку в существующий обработчик Etsy и открывает оплату после успешного ответа обработчика.

Обновление оплаченной сделки в CRM требует отдельно настроенного серверного webhook Stripe.
